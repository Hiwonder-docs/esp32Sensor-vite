20. AI Voice Interaction Module ​

20.1 Introduction ​

The AI voice interaction module recognizes and speaks words using the CI1302 chip. It includes offline neural network acceleration and dedicated speech processing hardware, using noise cancellation and deep learning models to process audio and recognize voice commands quickly. The module operates with a voice wake-up system, requiring the wake-up word before it begins listening for commands.

With easy setup and accurate speech recognition, this module works great for smart homes, conversational bots, educational robots, and smart vehicle projects.

20.4 Voice Interaction Testing ​

  1. Connect the Type-C port of the AI voice interaction module to a computer port or a phone charger using a USB cable for power supply.
  1. Testing voice interaction with the command Go straight serves as an example. First, speak the wake-up word Hello Hiwonder to wake up the module. When the module replies I'm here, it is ready to recognize commands.
  1. Next, say the command Go straight to hear the corresponding voice reply.
  1. The module also responds to the following voice commands, triggering spoken replies from WonderEcho.

20.5 Hands-On Project ​

20.5.1 Project Overview ​

This project uses the AI voice interaction module to listen for voice commands in a continuous loop and print matching messages to the console. It covers module setup, reading speech recognition data, and using multi-branch conditional statements.

20.5.2 Hardware Wiring ​

  • Connect the AI voice interaction module to port P1 of the controller using a 4-pin module cable.

NOTE

This module supports connection to any port among P1, P2, P3, or P4 on the controller. Ensure that the port configured in the program matches the physical wiring.

20.5.3 Adding Extensions ​

  • Select WonderEcho voice module under the Sensor category.

20.5.4 Complete Program and Analysis ​

  1. Upon start-up, the hardware port of the AI voice interaction module is initialized to port P1.

  2. Inside the main program loop, the recognized word ID is stored into variable result to perform multi-branch conditional judgment:

    • If result = 1, corresponding to the "Go straight" command, the program prints "Go forward!" to the serial monitor.

    • If result = 2, corresponding to the "Go backward" command, the program prints "Go back!" to the serial monitor.

    • If result = 3, corresponding to the "Turn left" command, the program prints "Turning left!" to the serial monitor.

    • If result = 4, corresponding to the "Turn right" command, the program prints "Turning right!" to the serial monitor.

    • Under all other conditions, the program prints "Reading..." to the serial monitor.

  3. A 0.5 s delay at the end of each loop iteration regulates data polling rate and maintains stable serial output.

NOTE

The source files are available for download under Program Files/20 AI Voice Module.sb3.

20.5.5 Program Upload ​

  • Click Connect device, select the serial port, then click the upload button. Wait for the upload success notification to complete the program transfer.

20.5.6 Program Outcome ​

Once the program upload is complete, check the serial monitor in the lower-right corner of the programming software. Wake up the module, then say "Go straight" to display "Go forward!" in the console. Saying "Go backward" displays "Go back!", saying "Turn left" displays "Turning left!", and saying "Turn right" displays "Turning right!". The module continues listening for voice commands in a continuous loop.

20.6 Firmware Update ​

NOTE

This module comes pre-flashed with factory firmware and does not require re-flashing under normal conditions. This guide is intended only for firmware updates or recovery from corrupted firmware.

  1. Connect the Type-C port on top of the AI voice interaction module to a computer using a USB cable.
  1. Open the PACK_UPDATE_TOOL application located in the Appendix/02 AI Voice Interaction Module/01 Flashing Tool directory.
  1. Select the CI1302 chip from the dropdown menu, then click Update.
  1. Click Select firmware to choose the bin file for flashing, then select the WonderEcho Flash‑firmware 20260901.bin file located in the Appendix/02 AI Voice Interaction Module/02 Firmware directory.
  1. Locate the corresponding COM port and click to select its checkbox.
  1. Press the RST button on the AI voice interaction module to enter flashing mode, then wait for the update to complete successfully.
