21. WonderLLM Module ​

21.1 Module Overview ​

21.1.1 Introduction ​

The WonderLLM AI module integrates a high-performance ESP32-S3 chip, a 2-megapixel high-definition camera, a microphone, an LCD screen, a speaker, and a CI1302 voice recognition chip. It integrates multimodal AI models spanning text, speech, and vision.

Designed for easy integration with robotics kits, the module acts as an intelligent processing core. It interprets spoken commands and delivers advanced perception, reasoning, and execution capabilities, creating a natural and responsive human-robot interaction experience.

21.1.2 Technical Specifications ​

21.1.3 Hardware Interface Description ​

The corresponding functions are outlined in the following table:

ItemFunction
1Top Type-C port: Uploads ESP32-S3 program firmware
2Bottom Type-C port: Uploads CI1302 voice recognition firmware
34-pin I2C port: Supports secondary development
4Capacitive touchscreen: Displays visuals and adjusts volume
5Left button, Button A: Toggles between Expression Mode and Chat Mode
6High-definition camera: Captures live images
7Right button, Button B: Configures network settings and controls interaction

21.1.4 Precautions ​

  1. Power the module using a 5 V power supply. Higher voltages will damage the module.

  2. Operate the module in a quiet environment. Excessive background noise interferes with recognition performance.

  3. Speak clearly at a moderate pace and stay within 5 m of the module.

21.2 Module Configuration ​

21.2.1 Powering On the Device ​

  1. The module supports power input through three ports: the top Type-C port, the bottom Type-C port, or the 4-pin I2C communication port. Connect an external power source to any of these ports to power on the module.
  1. Upon initial start-up, the screen displays the device hotspot name and the browser configuration URL, accompanied by a voice prompt. Complete the network configuration by following the steps in 21.2.2 Network Configuration.
  1. After connecting to Wi-Fi, the module must pair with the agent on the platform. The screen displays the device ID and the platform binding URL, broadcasting the binding verification code. Complete the platform binding process by following 21.2.3 Device Binding.
  1. If device binding is already complete upon power-up, a white circular progress bar appears on the screen while the module automatically connects using stored Wi-Fi credentials. If the connection fails, the screen displays the device hotspot name and the browser configuration URL along with a voice prompt. Reconfigure the Wi-Fi settings by referring to 21.2.2 Network Configuration.
  1. If the module has completed device binding and the stored Wi-Fi credentials match an available network, the circular progress indicator completes loading and the system transitions to the expression display interface. The module is now ready for human-robot interaction once activated with the wake-up word.

21.2.2 Network Configuration ​

(1) Configuration Modes ​

The module enters network configuration mode under three conditions:

  1. The module powers on for the first time or after firmware flashing, with no stored Wi-Fi credentials in memory.
  2. The current environment does not contain any Wi-Fi hotspot matching the stored credentials.
  3. A manual trigger initiates configuration mode by long-pressing Button A.

(2) Operating Steps ​

  1. Upon start-up, the module begins connecting to the network. The screen displays the device hotspot name and the browser configuration URL, accompanied by a voice prompt. The AI module activates its built-in hotspot for pairing. Hotspot names vary across devices in the format of Robot-xxxx. The following steps use hotspot Robot-B7B9 as an example.
  1. Search for the corresponding hotspot on a computer or smartphone and connect. This hotspot requires no password.
  1. Click the Network Configuration link, or enter the URL below into any web browser to open the network configuration page.
py
http://192.168.4.1
  1. Enter the desired Wi-Fi network name into field ① and the password into field ②. Click Connect at ③ to initiate the connection. The module attempts to match and connect to the specified Wi-Fi hotspot in the local environment.
  1. The page lists all available Wi-Fi hotspots detected by the module. Clicking an entry automatically populates field ① with the corresponding network name for faster configuration.
  1. If the prompt shown below appears, the specified hotspot cannot be found or the password is incorrect. Re-enter the credentials.
  1. If the success prompt appears, the module has established a connection. The module reboots automatically and connects to the designated Wi-Fi network.

NOTE

  • Do not enter credentials for Wi-Fi networks that cannot be detected, have weak signal strength, or lack internet access.

  • Newly saved network credentials coexist with previously saved configurations. Upon subsequent start-ups, the module scans each saved entry sequentially to attempt connection.

  • If the message "Error: Failed to check for new version, retrying in xx seconds" appears after network setup, the current network may lack internet access or suffer from poor connectivity. Switch to another Wi-Fi network.

(3) Entering Network Configuration Mode Manually ​

  1. The WonderLLM module supports manual entry into network configuration mode, allowing custom hotspot selection.

  2. After powering on the module, long-press Button A to issue the configuration command. The module enters network configuration mode immediately. Release the button once the mode activates.

  1. Entering configuration mode does not erase existing Wi-Fi profiles.

(4) Managing Saved Network Configurations ​

  1. While the module is in configuration mode, access the network configuration web page through the hotspot. A list of all previously saved Wi-Fi connections appears as shown below:
  1. Click the icon next to any entry to delete it. Click the icon to raise its priority during network pairing. The connection priority decreases from top to bottom.

21.3 Volume Control ​

21.3.1 Touchscreen Volume Adjustment ​

  1. After powering on and connecting to a Wi-Fi hotspot, adjust the module volume via touchscreen in either of two screens: ① Expression screen, ② Chat screen.

  2. Swipe vertically anywhere across the screen. Swiping upward increases the volume, while swiping downward decreases the volume. The adjustment increment depends on the swipe distance. Multiple continuous swipes are supported.

  3. While swiping to adjust the volume, the numerical volume level appears at the top center of the screen. The image below shows an upward swipe on the Expression screen to increase the volume:

21.3.2 Voice Command Volume Adjustment ​

  1. During interaction with the WonderLLM AI module, adjust the speaker volume via spoken voice commands.

  2. Enter the Chat screen by speaking the wake-up word or short-pressing the right button. Once the module activates, state a command using phrases such as:

    • "Set the volume to xx", where the valid integer range is 0 to 100, or expressed as a percentage.
    • "Turn up the volume", which allows the module to adjust the level automatically.

  3. Upon recognition, the dialogue box returns the internal volume control function call. Next, the dialogue box displays the spoken response from the language model and broadcasts the audio simultaneously. The generated reply varies while maintaining appropriate semantic meaning.

21.4 Chat Mode ​

21.4.1 Overview ​

  1. In this mode, the module listens to and interprets spoken statements, generating contextual responses.

  2. The operational state transitions among various modes are illustrated below. Enter Chat Mode from any other mode by speaking the wake-up word or short-pressing the right button.

21.4.2 Operating Instructions ​

  1. After completing network configuration, the module displays the Expression screen first:

  1. Speak the designated wake-up word, where the factory default is "Hello Hiwonder", or short-press Button B on the right to enter Chat Mode. A prompt tone sounds through the buzzer, the screen switches to the Chat screen, and the module begins listening for speech.

  2. When entering Chat Mode via wake-up word, the module automatically sends "Hello" as the opening greeting. The language model generates a spoken reply displayed in the chat interface. This greeting can be interrupted manually to save time, as detailed in 21.8 Free Conversation. The module then begins listening for spoken input.

  1. When entering Chat Mode by short-pressing the right button, the module begins listening for spoken input immediately without greeting output.
  1. During conversational interaction, the screen can remain on the Expression screen instead of switching to the chat box. Refer to 21.5 Expression Mode for detailed instructions.

21.5 Expression Mode ​

NOTE

  • If no wake-up word is detected on the Expression screen for over 20 s, the module enters Weather Clock Mode. Tap anywhere on the screen to return to Expression Mode.

  • Toggling between the two modes changes the interface display style during Chat Mode.

  • While short-pressing the left button to toggle the display style, the module remains in Expression Mode. Short-pressing the left button does not wake up the module to start active conversation.

  • Specifically, when setting the display style to Chat Mode, waking up the module via wake-up word or the right button opens the chat box interface with printed replies.

  • When setting the display style to Expression Mode, waking up the module keeps the animated face on screen while generating corresponding facial expressions matching the spoken replies.

21.5.1 Overview ​

  1. In this mode, the module mimics human facial expressions and emotional states.

  2. Transitions among various modes are illustrated below. Enter Expression Mode through any of the following actions:

    • Tap the screen once while in Weather Clock Mode.
    • Double-tap the screen while in Camera Mode.
    • Short-press the right button while in Chat Mode when the module is not speaking.

21.5.2 Operating Instructions ​

  1. While in Expression Mode, short-press the left button to toggle between Chat Mode and Expression Mode display styles. The active display style appears at the top of the screen.
  1. With the display style set to Expression Mode, wake up the module via wake-up word or the right button. The module responds with animated expressions based on spoken interaction, using either of two invocation patterns:
    • Describe a specific scenario or story, allowing the module to express suitable emotions automatically during response.
    • State a direct instruction such as "Show me a happy expression".

21.6 Weather Clock Mode ​

NOTE

While in Weather Clock Mode, tap anywhere on the screen to return to Expression Mode, or enter Chat Mode by speaking the wake-up word or short-pressing the right button.

21.6.1 Overview ​

  1. In this mode, the module retrieves real-time weather and time data for the configured city and presents it on screen.

  2. The state transitions are illustrated below. Enter Weather Clock Mode by leaving the screen idle for 20 s or tapping the screen once while in Expression Mode. Direct switching from Camera Mode or Chat Mode to Weather Clock Mode is not supported.

21.6.2 Operating Instructions ​

  1. In Expression Mode, tap anywhere on the screen or remain idle for 20 s to switch to Weather Clock Mode.

  1. Once in Weather Clock Mode, the module remains in this mode unless another action is triggered.

  2. In this mode, the screen presents the following information:

    • Local real-time weather and a 2-day weather forecast.
    • Current time and date.
    • Configured city location, with factory default set to Shenzhen, Guangdong.

  3. The location city can be modified. Activate the module by speaking the wake-up word or short-pressing the right button, then issue a voice command such as:

    • "Change the city", followed by a prompt requesting the target city.
    • "Switch the location city to New York". Following the spoken confirmation, the city on the weather clock updates synchronously.

21.7 Camera Mode ​

21.7.1 Overview ​

  1. In this mode, the module continuously captures and displays real-time video frames using the onboard camera.

  2. Transitions are illustrated below. Enter Camera Mode by double-tapping the screen while in Expression Mode. Direct switching from Weather Clock Mode or Chat Mode to Camera Mode is not supported.

21.7.2 Operating Instructions ​

  1. While in Expression Mode, double-tap anywhere on the screen to switch to Camera Mode.

  1. In Camera Mode, the module continuously captures real-time images and displays the live feed on screen. Without further input, the module maintains this display.

  2. In Camera Mode, tapping the screen once triggers the scene understanding feature, described in 21.9 Scene Understanding.

21.8 Free Conversation ​

21.8.1 General Operation ​

  1. After powering on and completing network configuration, wake up the module by speaking the wake-up word or short-pressing the right button to enter Chat Mode.

  2. Speak naturally to the module. Connected cloud models interpret the input, returning text and synthesized speech. The module retains dialogue context to support multi-turn conversations.

  3. Following each conversation exchange, including after wake-up, the module continues listening. If no speech is recognized within 1 minute, the module terminates the listening session automatically. The language model speaks a farewell message displayed in the chat box. To resume interaction, wake up the module again by speaking the wake-up word or short-pressing the right button.

  4. To conclude a conversation actively, issue an exit command such as "Goodbye" or "That is all for now". Upon receiving the command, the module speaks a farewell response and ceases listening.

  5. The WonderLLM module supports speech interruption. While the module is speaking, including during response delivery, greeting, or farewell, short-press the right button to stop the audio broadcast immediately and begin listening for the next spoken input.

  6. The module supports bilingual speech recognition and generation in Chinese and English. Switch the language directly using voice commands such as "Speak Chinese" or "Chat in English".

21.8.2 Calling Special Functions ​

(1) Overview ​

The module includes built-in capabilities accessible via spoken commands during conversational interaction. Inquire about available functions using phrases like "List available capabilities" or "Introduce system functions". The table below outlines supported functions:

(2) Invocation Examples ​

Execute specific functions using sample prompts:

  1. Weather inquiry: "Check the weather in Los Angeles."
  1. News broadcast: "Broadcast today's top news" or "Tell me about today's trending events."
  1. Outfit recommendation: "What should I wear when going out today?"

NOTE

When using the music playback function, lower the module volume beforehand to maintain a comfortable listening level.

21.9 Scene Understanding ​

NOTE

  • Scene understanding does not support continuous streaming analysis. It captures a single static image upon instruction and processes that frame.

  • While in Camera Mode, double-tap the screen again to return to Expression Mode.

  • Before tapping to trigger analysis in Camera Mode, the module only streams live video on screen without invoking large vision models.

21.9.1 Voice Command Triggering ​

  1. Power on the module to display the Expression screen. Speak the wake-up word or short-press the right button to enter the Chat screen and activate the module.

  2. Issue a voice command using phrases such as "Describe the view ahead" or "Take a photo, please".

  3. Upon understanding the instruction, the camera captures a static image and displays it briefly on screen for visual confirmation. The dialogue box records the internal image capture function call. The vision-language model then analyzes the image, displaying the descriptive analysis in the chat interface and broadcasting the synthesized response simultaneously. The generated description varies while remaining contextually accurate.

21.9.2 Touchscreen Triggering ​

  1. While in Expression Mode, double-tap anywhere on the screen. The module enters Camera Mode, presenting a live feed from the camera on screen.
  1. While in Camera Mode, single-tap anywhere on the screen. The camera captures a still frame and displays it briefly for confirmation. The module then resumes Camera Mode and broadcasts the spoken image analysis automatically.

21.10 Hands-On Project ​

21.10.1 Project Overview ​

This project establishes communication between the controller and the WonderLLM AI module. The system reads the battery voltage of the robot, transmits the battery status packet to the AI module, and enables interactive battery level inquiries.

21.10.2 Hardware Wiring ​

  • Connect the WonderLLM module to port P1 of the controller using a 4-pin module cable.

NOTE

This module supports connection to any port among P1, P2, P3, or P4 on the controller. Ensure that the port configured in the program matches the physical wiring.

21.10.3 Adding Extensions ​

  • Select WonderLLM under the Input Module category.

21.10.4 Complete Program and Analysis ​

  1. Upon program start-up, initialize the WonderLLM module on port P1 to load default settings and enable bus communication.

  2. Inside the main infinite loop, read incoming data packets from the module continuously and verify packet validity.

  3. Upon identifying a sensor data frame, extract the battery voltage value, append it to the battery status list, and assemble the robot status packet.

  4. Once the status packet is assembled, transmit the status data to the AI module, clear the cache list, and send the action complete instruction.

  5. Apply a 0.1 s delay to refresh data transmission cyclically, maintaining ongoing battery data communication.

NOTE

The source files are available for download under 01 Program Files/21 WonderLLM.sb3.

21.10.5 Program Upload ​

  • Click Connect device, select the serial port, then click the upload button. Wait for the upload success notification to complete the program transfer.

21.10.6 Project Outcome ​

After uploading the program, speak the wake-up word "Hello Hiwonder" to wake up the module. Inquire about the battery level. The module retrieves the battery voltage from the controller automatically and broadcasts the status via voice.

21.11 Firmware Update ​

21.11.1 ESP32-S3 Firmware Flashing ​

  1. Connect the top Type-C port of the WonderLLM module to a computer using a USB cable.
  1. Open the flash_download_tool_3.9.7.exe file located in the Appendix/03 WonderLLM Module/WonderLLM Flashing Tool/ESP32-S3 Firmware Flashing Tool/flash_download_tool_3.9.7 directory.
  1. Set Chip Type to ESP32-S3, leave other settings at their default values, and click OK.
  1. Once the tool opens, click ... to select the firmware bin file. Navigate to the Appendix/03 WonderLLM Module/WonderLLM Firmware/Online directory and choose the WonderLLM_S3_V1.9.0-EN.bin file.
  1. Select the checkbox on the left and configure the remaining parameters as shown in the screenshot below. Set the COM port to match the port assigned to the module.

NOTE

If SPI MODE is set to DIO according to the configuration below and the module fails to operate normally after flashing, change SPI MODE to DOUT and flash the firmware again.

  1. Click ERASE to clear previously downloaded firmware. This step is mandatory. Wait until the status bar displays FINISH.
  1. Click START to flash the selected firmware. The flashing process finishes once the progress bar reaches completion.

21.11.2 CI1302 Firmware Flashing ​

  1. Connect the bottom Type-C port of the WonderLLM module to a computer using a USB cable.
  1. Open the PACK_UPDATE_TOOL.exe file located in the Appendix/03 WonderLLM Module/WonderLLM Flashing Tool/CI1302 Firmware Flashing Tool directory.
  1. Select the CI1302 chip and click Update.
  1. Click Select firmware to choose the bin file for flashing. Navigate to the Appendix/03 WonderLLM Module/WonderLLM Firmware/Online directory and select the CI1302-EN.bin file.
  1. Locate the assigned COM port and click to select its checkbox.
  1. Press and hold both Button A and Button B on the WonderLLM module simultaneously to enter flashing mode, then wait for the update to complete successfully.
