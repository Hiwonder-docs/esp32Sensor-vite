22. WonderLLM Offline Module ​

NOTE

The module comes pre-flashed with online large model firmware from the factory. To explore offline features, flash the offline firmware first.

22.1 Firmware Update ​

22.1.1 ESP32-S3 Firmware Flashing ​

  1. Connect the top Type-C port of the WonderLLM module to a computer using a USB cable.
  1. Open the flash_download_tool_3.9.7.exe file located in the Appendix/03 WonderLLM Module/WonderLLM Flashing Tool/ESP32-S3 Firmware Flashing Tool/flash_download_tool_3.9.7 directory.
  1. Set ChipType to ESP32-S3, leave other settings at their default values, and click OK.
  1. When the tool interface opens, click ... to select the firmware bin file. Navigate to the Appendix/03 WonderLLM Module/WonderLLM Firmware/Offline directory and choose the WonderLLM_Echo_S3_V1.9.0.bin file.
  1. Select the checkbox on the left and configure the remaining parameters as shown in the screenshot below. Set the COM port to match the port assigned to the module.

NOTE

If SPI MODE is set to DIO according to the configuration below and the module fails to operate normally after flashing, change SPI MODE to DOUT and flash the firmware again.

  1. Click ERASE to clear previously downloaded firmware. This step is mandatory. Wait until the status bar displays FINISH.
  1. Click START to flash the selected firmware. The flashing process finishes once the progress bar reaches completion.

22.1.2 CI1302 Firmware Flashing ​

  1. Connect the bottom Type-C port of the WonderLLM module to a computer using a USB cable.
  1. Open the PACK_UPDATE_TOOL.exe file located in the Appendix/03 WonderLLM Module/WonderLLM Flashing Tool/CI1302 Firmware Flashing Tool directory.
  1. Select the CI1302 chip and click Update.
  1. Click Select firmware to choose the bin file for flashing. Navigate to the Appendix/03 WonderLLM Module/WonderLLM Firmware/Offline directory and select the CI1302_K12_Echo.bin file.
  1. Locate the assigned COM port and click to select its checkbox.
  1. Press and hold both Button A and Button B on the WonderLLM module simultaneously to enter flashing mode, then wait for the update to complete successfully.

22.2 Voice Interaction Mode ​

22.2.1 Overview ​

  1. After updating both firmware files to the offline version, the module enters the Standby state first.
  1. In any mode, long-press the right button, Button B, to enter Voice Interaction Mode.
  1. Activate the module by speaking the wake-up word Hello Hiwonder. The module responds with I'm here.
  1. In Voice Interaction Mode, the module replies with designated responses to recognized command phrases. The list below presents frequently used voice commands, with full protocol details documented in the appendix.
  1. After each conversational exchange, including upon wake-up, the module continues listening. If no speech is recognized within 1 minute, the module ceases listening and switches to the sleep screen automatically. To resume interaction, wake up the module again with the designated wake-up word.

22.2.2 Hands-On Project ​

(1) Project Overview ​

This project demonstrates offline voice recognition using the WonderLLM offline module. When the module identifies a preset voice command, it returns a specific command ID. The controller then reads this value and prints action messages to the serial monitor, providing interactive feedback for spoken instructions.

(2) Hardware Wiring ​

  • Connect the WonderLLM module to port P1 of the controller using a 4-pin module cable.

NOTE

This module supports connection to any port among P1, P2, P3, or P4 on the controller. Ensure that the port configured in the program matches the physical wiring.

(3) Adding Extensions ​

  • Select WonderLLM-offline under the Input Module category.

(4) Complete Program and Analysis ​

  1. Upon start-up, initialize the WonderLLM offline module on port P1 and switch the module to Voice Interaction Mode.

  2. In the main program loop, continuously retrieve speech recognition results and store them into variable result for multi-branch condition evaluation:

    • If result = 1, indicating the "go forward" command, print "Going forward!" to the serial monitor.

    • If result = 2, indicating the "go backward" command, print "Going back!" to the serial monitor.

    • If result = 3, indicating the "turn left" command, print "Turning left!" to the serial monitor.

    • If result = 4, indicating the "turn right" command, print "Turning right!" to the serial monitor.

    • Otherwise, print "Reading..." to the serial monitor.

  3. Apply a 0.5 s delay at the end of each loop iteration to regulate data polling frequency and maintain stable serial output.

NOTE

The source files are available for download under 01 Program Files/22-1 WonderLLM Voice Interaction.sb3.

(5) Program Upload ​

  • Click Connect device, select the serial port, then click the upload button. Wait for the upload success notification to complete the program transfer.

(6) Project Outcome ​

After uploading the program, observe the serial monitor in the lower-right corner of the programming software. Speak the wake-up word Hello Hiwonder to wake up the module. Speak "go straight", and the console prints "Go forward!". Speak "go backward", and the console prints "Go back!". Speak "Turn left", and the console prints "Turning left!". Speak "Turn right", and the console prints "Turning right!". The system listens for voice commands continuously in a loop.

22.3 Face Recognition Mode ​

22.3.1 Overview ​

In any mode, short-press the right button, Button B, to enter Face Recognition Mode.

22.3.2 Hands-On Project ​

(1) Project Overview ​

This project uses Face Recognition Mode on the WonderLLM offline module. When the camera detects a face, the controller plays note C5 on the buzzer. Otherwise, the buzzer turns off, pairing face detection with audio feedback.

(2) Hardware Wiring ​

  • Connect the WonderLLM module to port P1 of the controller using a 4-pin module cable.

NOTE

This module supports connection to any port among P1, P2, P3, or P4 on the controller. Ensure that the port configured in the program matches the physical wiring.

(3) Adding Extensions ​

  • Select WonderLLM-offline under the Input Module category.

(4) Complete Program and Analysis ​

  1. Upon start-up, initialize the WonderLLM offline module on port P1 and switch the module to Face Recognition Mode.

  2. In the main program, poll the detection status continuously through a loop to evaluate whether a face is detected:

    • If a face is detected, play note C5 for half a beat in the background.

    • If no face is detected, turn off the buzzer to silence audio output.

  3. Apply a 0.1 s delay at the end of each iteration, repeating the face detection sequence cyclically.

NOTE

The source files are available for download under 01 Program Files/22-2 WonderLLM Face Recognition.sb3.

(5) Program Upload ​

  • Click Connect device, select the serial port, then click the upload button. Wait for the upload success notification to complete the program transfer.

(6) Project Outcome ​

After uploading the program, position a face in front of the camera. When the module detects the face, the buzzer plays note C5. Moving out of view turns off the buzzer.

22.4 Color Recognition Mode ​

22.4.1 Overview ​

In any mode, short-press the left button, Button A, to enter Color Recognition Mode.

The color IDs and corresponding colors are listed below:

22.4.2 Hands-On Project ​

(1) Project Overview ​

This project uses the WonderLLM offline module in Color Recognition Mode. The camera identifies the color ID of the largest color block in the frame. Based on the recognition result, the controller regulates the onboard RGB LEDs to display the corresponding color, linking color identification with visual lighting feedback.

(2) Hardware Wiring ​

  • Connect the WonderLLM module to port P1 of the controller using a 4-pin module cable.

NOTE

This module supports connection to any port among P1, P2, P3, or P4 on the controller. Ensure that the port configured in the program matches the physical wiring.

(3) Adding Extensions ​

  • Select WonderLLM-offline under the Input Module category.

(4) Complete Program and Analysis ​

  1. Upon start-up, initialize the WonderLLM offline module on port P1 and switch the module to Color Recognition Mode.

  2. In the main program, continuously read the color ID of the largest detected area in the frame and evaluate the detected ID:

    • If color ID 1 is identified, illuminate all RGB LEDs in red.

    • If color ID 3 is identified, illuminate all RGB LEDs in green.

    • If color ID 4 is identified, illuminate all RGB LEDs in blue.

    • If no matching color is found, turn off all RGB LEDs.

  3. Apply a 0.1 s delay at the end of each iteration, repeating the color recognition process cyclically.

NOTE

The source files are available for download under 01 Program Files/22-3 WonderLLM Color Recognition.sb3.

(5) Program Upload ​

  • Click Connect device, select the serial port, then click the upload button. Wait for the upload success notification to complete the program transfer.

(6) Project Outcome ​

After uploading the program, present a red color block to the camera. The RGB LEDs illuminate in red. Present a green color block, and the RGB LEDs turn green. Present a blue color block, and the RGB LEDs illuminate in blue. Removing the color block from view turns off all RGB LEDs.
